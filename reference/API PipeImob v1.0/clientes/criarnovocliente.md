excerpt: "Essa rota permite cadastrar um novo cliente final vinculado a uma imobiliária, incluindo informações pessoais, dados do cônjuge, representantes legais e eventuais documentos.\n\nNão é possível vincular tal novo cliente cadastrado via API a uma transação. Isto deve ser feito pela própria interface do PipeImob, nos formulários das transações, para garantia às regras de negócios internas.\n\n### **📋\_ Regras de Negócio**\n\nNa tentativa de inclusão de cliente:  \n\n❌ A inclusão será **impedida** e retornará erro quando:\n\n- As **credenciais forem inválidas**\n    \n- As **credenciais não tiverem permissão** para a rota\n    \n- Estiverem faltando **campos obrigatórios**\n    \n- O **CPF ou CNPJ for inválido**\n    \n- O **CPF/CNPJ já estiver cadastrado para a mesma imobiliária**\n    \n- Os valores informados nos campos ENUM não forem válidos\n    \n\n✅ Na **inclusão com sucesso**:\n\n- Será retornado um uniqueId do cliente\n    \n- Os arquivos em documentos, se enviados corretamente, serão **baixados e anexados ao cliente**\n    \n\n### **📂\_ Observação sobre documentos**\n\n- O campo documentos é opcional e aceita uma lista de arquivos.\n    \n- Cada item da lista deve conter:\n    \n    - url: link público para download do arquivo.\n        \n    - nomeArquivo: nome amigável do documento.\n        \n    \n- **Importante:**\n    \n    - Os **links devem ser públicos e diretamente acessíveis**.\n        \n    - **Não é possível usar links do Google Drive**, pois o Google não permite o download de arquivos via requisições backend de forma direta e automatizada.\n        \n    \n\n### **📚\_ ENUMs Válidos**\n\n#### **tipoPessoa**\n\n- PF\n    \n- PJ\n    \n\n#### **estadoCivil**\n\n- casado\n    \n- uniaoestavel\n    \n- solteiro\n    \n- viuvo\n    \n- divorciado\n    \n\n#### **genero**\n\n- masculino\n    \n- feminino\n    \n\n#### **regimeMatrimonial**\n\n- comunhaoparcial\n    \n- comunhaouniversal\n    \n- separacaoconvencional\n    \n- separacaoobrigatoria\n    \n- participacaoaquestos\n    \n\n#### **representanteTipoRepresentacao**\n\n- procuracao\n    \n- alvarajudicial\n    \n- contratosocial\n    \n- estatutosocial\n    \n- outro"
